DYNAMIC OBJECT / GT INCOMPLETENESS

关键案例：RGB 里有鱼，GT 里鱼没了，但预测里还有鱼

这类 case 说明 Benchmark GT 可能存在 dynamic-object / coverage incompleteness。模型预测出输入图像中真实可见的鱼，但 GT 对应区域缺失时，GT-based metric 可能反而惩罚这部分预测。

① RGB · 鱼真实可见

② Filtered GT · 鱼区域缺失 / 被过滤

③ Wat3R · 仍预测出鱼的几何

④ Water-VGGT · 仍预测出鱼的几何

评价含义：这不能自动证明“模型一定对、GT 一定错”，因为预测出来的鱼深度仍可能不准确；但它明确说明：Water3D 部分 GT 对动态物体可能存在 coverage / filtering incompleteness。因此单独看 GT-based metric 可能低估某些视觉上合理的预测，必须结合 RGB、Depth 和 Point Cloud 一起判断。
